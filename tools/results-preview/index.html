How the two awards work
  • Quality: highest test ROC-AUC among participant-trained models. Supplied Sophon is a reference, excluded from both awards.
  • Efficiency: lowest normalized inference time among models within 0.02 AUC of the best result.
  • The same 128 validation jets, one warmup and three measured repeats define the latency test. A common CPU calculation provides an approximate hardware correction.
  • Training time is reported separately. Sophon is pretrained and uses richer inputs; this compares complete approaches, not equal training budgets.
  • Use validation while improving your model. Submit one selected final test result and explain your choices.
